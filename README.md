# SoftSkills Web

Веб-приложение для диагностики и развития soft skills.

Дипломный проект — СПбГЭТУ «ЛЭТИ», 2026, Притчин А.А.

---

## Что делает

Пользователь проходит тест на оценку 5 навыков: коммуникация, лидерство, самоорганизация, эмпатия, критическое мышление. По результатам строится профиль компетенций, формируется персональная программа упражнений и рекомендации материалов для изучения.

Три формата теста: Экспресс (15 вопросов), Стандартный (25), Расширенный (50). Баллы нормализуются до шкалы 0–100, что позволяет сравнивать результаты разных форматов между собой.

Есть платный тариф с расширенным набором упражнений и возможностью повторного прохождения теста для отслеживания динамики.

## Стек

**Фронтенд** — React 18, TypeScript, Vite, React Router, Recharts

**Бэкенд** — Node.js, Fastify, TypeScript, Prisma ORM

**База данных** — PostgreSQL

**Авторизация** — JWT (токен в localStorage)

---

## Запуск

Нужны Node.js 18+ и PostgreSQL.

### Бэкенд

```bash
cd backend
npm install
```

Создай `backend/.env`:

```env
DATABASE_URL="postgresql://user:password@localhost:5432/softskills"
JWT_SECRET="любая-длинная-строка"
PORT=3001
CLIENT_URL="http://localhost:5173"
ADMIN_EMAILS="твой@email.com"
```

```bash
npx prisma migrate dev
npm run db:seed
npm run dev
```

### Фронтенд

```bash
cd frontend
npm install
```

Создай `frontend/.env`:

```env
VITE_ADMIN_EMAILS=твой@email.com
```

```bash
npm run dev
```

Открыть: http://localhost:5173

## Административная панель

Доступна по `/admin` пользователям из `ADMIN_EMAILS`. Включает четыре раздела:

- **Статистика** — количество пользователей, оплат, средние баллы по навыкам
- **Пользователи** — просмотр профилей, результаты теста, управление платным доступом
- **Вопросы** — добавление и удаление вопросов теста
- **Материалы** — CRUD для учебных материалов с прикреплением файлов
